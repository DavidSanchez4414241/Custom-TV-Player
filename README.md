Guía de Uso — Custom TV Player 📺

Puedes descargar la aplicación desde Releases (Salidas). Una vez que estés en la aplicación, encontrarás varios menús principales para gestionar todo tu contenido:
1. Menú Inicio: Añadir Canales o Importar Listas

    Añadir canal: Te permite configurar canales de forma individual rellenando los siguientes campos:

        Nombre (obligatorio).

        Logo (opcional).

        Tipo de stream: Debes seleccionar si es un stream directo (un archivo que termine, por ejemplo, en .m3u, .m3u8 o .mp4) o si por el contrario es una web/Streamlink (en cuyo caso introducirás la URL correspondiente).

        País y Categoría (ambos opcionales).

        Por último, haz clic en Guardar.

    Importar una lista: Accediendo al menú Mis canales > Importar o exportar listas, podrás importar listas completas en formato .m3u o .m3u8, así como importar o exportar toda tu configuración personal en un archivo .json.

2. Gestión de Categorías

    Cuentas con un apartado dedicado a Modificar las categorías. Por defecto, la aplicación incluye preconfiguradas las categorías de España y Comunidades Autónomas de España.

3. Ajustes de la Aplicación

    En el menú de ajustes, puedes personalizar la apariencia cambiando el tema del dispositivo a tu gusto.

4. Menú Plugins Python (Streamlink)

    Un apartado muy potente e interesante de la funcionalidad de Streamlink es el menú Plugins Python.

    Desde aquí puedes importar un solo plugin de manera individual o —lo que es más recomendable— importar una carpeta entera de plugins.

    Para esto último, solo tienes que colocar los archivos compatibles con Streamlink (con extensión .py) dentro de una carpeta en tu dispositivo (por ejemplo, en la carpeta de descargas) y seleccionar dicha carpeta para utilizar todos tus plugins personalizados de forma unificada.
